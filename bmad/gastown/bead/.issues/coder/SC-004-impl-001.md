### `createSnapshot()` Extension
```java
// After existing graph snapshot logic:
List<MavenDependency> allDeps = new ArrayList<>();
List<String> allRepos = new ArrayList<>();
try (Stream<Path> poms = Files.find(projectRoot, 10,
        (p, a) -> p.getFileName().toString().equals("pom.xml"))) {
    poms.forEach(pom -> {
        allDeps.addAll(supplyChainAnalyzer.parseDependencies(pom));
        allRepos.addAll(supplyChainAnalyzer.parseRepositoryUrls(pom));
    });
}
snapshot.dependencySnapshot = new DependencySnapshot(allDeps, allRepos);
```

Note: `DeltaAnalyzer` needs access to `projectRoot`. Confirm this is already stored or
passed as a parameter. If not, accept it as a parameter to `saveSnapshot(Path snapshotDir, Path projectRoot)`.

### Compare Logic
Identity key: `dep.groupId() + ":" + dep.artifactId()`

```java
Map<String, DependencyEntry> oldMap = index(old.dependencySnapshot.dependencies());
Map<String, DependencyEntry> newMap = index(new.dependencySnapshot.dependencies());
// added  = keys in newMap not in oldMap
// removed = keys in oldMap not in newMap
// versionChanged = keys in both with different version
// repositoriesAdded = urls in new not in old
```

### Text Report SNAPSHOT Flag
```java
String snapshotFlag = entry.version() != null
    && entry.version().endsWith("-SNAPSHOT") ? "  ⚠ SNAPSHOT" : "";
```
