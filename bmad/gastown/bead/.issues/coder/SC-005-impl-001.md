### Controller Method Sketch
```java
@GetMapping("/supply-chain")
@Operation(summary = "Supply chain risk analysis",
           description = "Detects Maven dependency risks and malicious code patterns")
public ResponseEntity<SupplyChainReport> getSupplyChainAnalysis(
        @RequestParam(required = false) String projectPath,
        @RequestParam(required = false) String compareSnapshot) {

    Path root = resolveProjectPath(projectPath);
    List<SupplyChainRisk> risks = supplyChainAnalyzer.analyze(root);
    List<MaliciousPatternViolation> patterns = forbiddenApiScanner.scanForMaliciousPatterns(root);
    DependencyDelta delta = compareSnapshot != null
        ? deltaAnalyzer.compareWithSnapshot(Path.of(compareSnapshot)).dependencyDelta()
        : null;
    Summary summary = new Summary(risks.size(), countBySeverity(risks, CRITICAL), ...);
    return ResponseEntity.ok(new SupplyChainReport(...));
}
```

### resolveProjectPath Helper
If `projectPath` param is null, fall back to the path stored in `GraphService` from the last scan.
If still null, return 400.
