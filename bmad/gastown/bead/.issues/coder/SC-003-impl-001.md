### pom.xml Parsing Strategy

Use Java's built-in `javax.xml.parsers.DocumentBuilder` (already available via JDK — no new dep):
```java
DocumentBuilderFactory factory = DocumentBuilderFactory.newInstance();
DocumentBuilder builder = factory.newDocumentBuilder();
Document doc = builder.parse(pomFile.toFile());
NodeList deps = doc.getElementsByTagName("dependency");
```
Extract `groupId`, `artifactId`, `version`, `scope` text content from each `<dependency>` element.
Also check `<repositories><repository><url>` elements for UNVERIFIED_REPOSITORY.

Walk directory tree with `Files.find()` to locate all `pom.xml` files and all embedded `.jar` files.

### Levenshtein Distance (TyposquatDetector)

Implement standard iterative 2-row DP in ~15 lines. No external library needed.
Only check distance against the *prefix* segment of each known groupId
(e.g. `org.apache.sling` → check `org.apache.sling` vs candidate; also check `org.apache` prefix).

### Spring Wiring

`TyposquatDetector` is a `@Component` injected into `SupplyChainAnalyzer` via constructor.
`SupplyChainAnalyzer` injects `GraphService` for node creation.
