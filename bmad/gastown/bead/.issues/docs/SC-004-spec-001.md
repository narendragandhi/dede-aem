# Specification: DeltaAnalyzer — Maven dependency tracking

## Overview

**Feature**: Extend `DeltaAnalyzer` to capture and diff Maven dependency state between snapshots.
**Inspiration**: supply-chain-monitor resumes from a saved serial/sequence and diffs what changed.
Here, the snapshot captures the full dependency tree of the project so two snapshots can be compared
to see *which dependencies were added, removed, or version-bumped*.

## Context

Dede's existing `DeltaAnalyzer` captures the code graph (nodes + edges) between runs. It does not
currently capture `pom.xml` state. An architect running `--compare` after a dependency audit wants to
see: "Since last week, 3 new dependencies were added. One is a SNAPSHOT. Flag for review."

## Functional Specification

### New Inner Classes in `DeltaAnalyzer`

```java
// Snapshot DTO — added to GraphSnapshot
public static class DependencySnapshot {
    List<DependencyEntry> dependencies;
    List<String> repositoryUrls;      // <repository><url> values
}

public static class DependencyEntry {
    String groupId, artifactId, version, scope;
}

// Delta DTO — added to DeltaReport
public static class DependencyDelta {
    List<DependencyEntry> added;
    List<DependencyEntry> removed;
    List<DependencyChange> versionChanged;  // {entry before, entry after}
    List<DependencyEntry> scopeChanged;      // same dep, different scope
    List<String> repositoriesAdded;
}

public static class DependencyChange {
    DependencyEntry before, after;
}
```

### Modified Methods

#### `saveSnapshot(Path directory)`
Call `SupplyChainAnalyzer.parseDependencies(Path)` for each `pom.xml` found under the project root.
Aggregate into `DependencySnapshot` and serialize alongside the existing graph snapshot JSON.

#### `compare(GraphSnapshot old, GraphSnapshot new)`
Populate `DeltaReport.dependencyDelta` by diffing `old.dependencies` vs `new.dependencies`
using `groupId + artifactId` as the identity key.

#### `generateTextReport(DeltaReport report)`
Add a `Dependency Delta` section if `dependencyDelta` is non-null:
```
=== Dependency Delta ===
Added (2):   com.example:new-lib:1.0.0 [compile]
             org.evil:payload:1.0.0-SNAPSHOT [runtime]  ⚠ SNAPSHOT
Removed (1): com.old:legacy:0.9.0 [test]
Version bumps (1): org.apache.sling:org.apache.sling.api  2.26.0 → 2.27.2
Repos added (0):
```
