# Test: DeltaAnalyzer Maven dependency tracking

## Context

Write tests for the new dependency snapshot and delta logic in `DeltaAnalyzer`.

**Implementation**: bmad/gastown/bead/.issues/coder/SC-004-impl-001.md

## Test Requirements

- [ ] `compare()` correctly identifies added dependencies
- [ ] `compare()` correctly identifies removed dependencies
- [ ] `compare()` correctly identifies version-changed dependencies
- [ ] `compare()` correctly identifies newly added repository URLs
- [ ] `generateTextReport()` includes SNAPSHOT warning for flagged deps
- [ ] Jackson round-trip: snapshot serializes and deserializes with `dependencySnapshot` intact
- [ ] Null-safe: old snapshot without `dependencySnapshot` (legacy) does not throw NPE
- [ ] All 116 baseline tests still pass

## Test Scenarios

### Added Dependency
```
old: [] (empty)
new: [com.example:new-lib:1.0.0:compile]
Expected: delta.added = [com.example:new-lib:1.0.0:compile]
          delta.removed = []
          delta.versionChanged = []
```

### Removed Dependency
```
old: [com.old:removed-lib:0.9.0:test]
new: []
Expected: delta.removed = [com.old:removed-lib:0.9.0:test]
```

### Version Change
```
old: [org.apache.sling:org.apache.sling.api:2.26.0:provided]
new: [org.apache.sling:org.apache.sling.api:2.27.2:provided]
Expected: delta.versionChanged[0].before.version = "2.26.0"
          delta.versionChanged[0].after.version  = "2.27.2"
```

### SNAPSHOT Warning in Report
```
added: [com.evil:payload:1.0.0-SNAPSHOT:runtime]
Expected: generateTextReport() output contains "⚠ SNAPSHOT"
```

### Legacy Snapshot (no dependencySnapshot field)
```
GraphSnapshot with dependencySnapshot = null
compare(null-dep-snapshot, new-snapshot) -> dependencyDelta is null or treated as all-added
No NullPointerException thrown
```
