# Test: GET /api/analysis/supply-chain endpoint

## Context

Write MockMvc controller tests for the new supply chain endpoint.

**Implementation**: bmad/gastown/bead/.issues/coder/SC-005-impl-001.md

## Test Requirements

- [ ] 200 response with valid JSON structure
- [ ] `supplyChainRisks` array populated from mocked `SupplyChainAnalyzer`
- [ ] `maliciousPatterns` array populated from mocked `ForbiddenApiScanner`
- [ ] `dependencyDelta` is null when `compareSnapshot` param not provided
- [ ] `dependencyDelta` is populated when `compareSnapshot` param provided
- [ ] 400 returned when `projectPath` cannot be resolved
- [ ] `summary.totalRisks` equals `supplyChainRisks.size()`
- [ ] All 116 baseline tests still pass

## Test Scenarios

### Happy Path — No Snapshot Compare
```
GET /api/analysis/supply-chain?projectPath=/tmp/fake-project
Mocks: SupplyChainAnalyzer returns 1 SNAPSHOT risk
       ForbiddenApiScanner returns 0 patterns
Expected: 200, supplyChainRisks.length=1, dependencyDelta=null,
          summary.totalRisks=1, summary.highCount=1
```

### Happy Path — With Snapshot Compare
```
GET /api/analysis/supply-chain?projectPath=/tmp/fake&compareSnapshot=/tmp/snap.json
Mocks: DeltaAnalyzer.compareWithSnapshot returns delta with 1 added dep
Expected: 200, dependencyDelta.added.length=1
```

### Missing Project Path
```
GET /api/analysis/supply-chain (no params, no prior scan path in GraphService)
Expected: 400 Bad Request
```

### Serialization Check
Response JSON must not contain null fields for `supplyChainRisks` and `maliciousPatterns`
(return empty arrays not null).
