# Specification: SupplyChainAnalyzer service

## Overview

**Feature**: New `com.dede.supply` package with a Spring `@Service` that analyzes all `pom.xml` files
in a scanned project to detect Maven-level supply chain risks.
**Inspiration**: elastic/supply-chain-monitor watchlist + diff monitoring translated to the Maven ecosystem.

## Context

supply-chain-monitor monitors *which packages land in the registry*. The Maven equivalent is monitoring
*which packages land in your pom.xml*. An AEM project's `pom.xml` tree is the bill-of-materials; risky
entries here can introduce malicious transitive dependencies before any Java is even compiled.

## Functional Specification

### New Classes

#### `MavenDependency` (record)
```java
public record MavenDependency(
    String groupId,
    String artifactId,
    String version,   // may be null if managed via BOM
    String scope      // compile, runtime, test, provided
) {}
```

#### `SupplyChainRisk` (record)
```java
public record SupplyChainRisk(
    RiskType riskType,
    ForbiddenApiCatalog.Severity severity,
    String message,
    MavenDependency dependency
) {
    public enum RiskType {
        SNAPSHOT_IN_PRODUCTION_SCOPE,  // SNAPSHOT version in compile/runtime scope
        TYPOSQUATTED_GROUP_ID,         // groupId suspiciously similar to a known publisher
        UNVERIFIED_REPOSITORY,         // custom <repository> not in allowed list
        EMBEDDED_JAR                   // .jar file bundled inside /apps content package
    }
}
```

#### `SupplyChainAnalyzer` (service)
```java
@Service
public class SupplyChainAnalyzer {
    public List<SupplyChainRisk> analyze(Path projectRoot) { ... }
}
```

#### `TyposquatDetector` (component)
Computes Levenshtein distance between a candidate groupId prefix and each entry in
`known-publishers.json`. Flag if distance == 1 and candidate is NOT itself in the allowlist.

### known-publishers.json
Allowlist resource at `src/main/resources/known-publishers.json`:
```json
{
  "knownGroupIds": [
    "org.apache.sling", "org.apache.jackrabbit", "com.adobe.aem",
    "com.adobe.cq", "com.adobe.granite", "com.day.cq",
    "org.springframework", "org.springframework.boot",
    "com.fasterxml.jackson", "org.osgi", "org.slf4j",
    "ch.qos.logback", "com.google.guava", "commons-lang",
    "commons-collections", "commons-io", "org.mockito",
    "junit", "org.junit", "javax.servlet", "jakarta.servlet"
  ]
}
```

### Detection Rules

| Risk Type | Condition |
|-----------|-----------|
| SNAPSHOT_IN_PRODUCTION_SCOPE | `version` ends with `-SNAPSHOT` AND `scope` is `compile` or `runtime` (or null = compile) |
| TYPOSQUATTED_GROUP_ID | Levenshtein distance to any known groupId prefix == 1 AND groupId not in allowlist |
| UNVERIFIED_REPOSITORY | `<repository>` URL does not start with `https://repo.maven.apache.org`, `https://repo1.maven.org`, or `https://repo.adobe.com` |
| EMBEDDED_JAR | `.jar` file found under `ui.apps/src/main/content/jcr_root/apps/` or `ui.content/` paths |
