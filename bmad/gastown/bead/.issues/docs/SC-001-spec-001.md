# Specification: SUPPLY_CHAIN violation categories in forbidden-apis.json

## Overview

**Feature**: Supply chain attack pattern categories
**Type**: JSON configuration
**Purpose**: Extend the forbidden-apis.json catalog with three new SUPPLY_CHAIN categories so
`ForbiddenApiScanner` and `ForbiddenApiCatalog` detect supply-chain-style attack patterns in AEM/OSGi source code.

## Context

elastic/supply-chain-monitor flags malicious npm/PyPI packages that contain:
- Process spawning (Runtime.exec, ProcessBuilder)
- Remote class loading (URLClassLoader with HTTP URLs)
- Reflection-based dynamic class loading (Class.forName on encoded/dynamic names)

These same patterns are red flags when found inside OSGi bundles. An AEM bundle has no legitimate reason to
spawn OS processes or load classes from the network.

## Functional Specification

### New Categories to Add

#### 1. SUPPLY_CHAIN_PROCESS_SPAWN
| Field | Value |
|-------|-------|
| severity | CRITICAL |
| classes | `java.lang.Runtime`, `java.lang.ProcessBuilder` |
| methods | `exec`, `start` |
| replacement | Use Sling Jobs (`org.apache.sling.event.jobs.JobManager`) for async work |

#### 2. SUPPLY_CHAIN_REMOTE_CLASSLOAD
| Field | Value |
|-------|-------|
| severity | CRITICAL |
| classes | `java.net.URLClassLoader` |
| methods | `loadClass` |
| replacement | All bundle classes must be declared in OSGi Import-Package; remote loading is forbidden |

#### 3. SUPPLY_CHAIN_REFLECTION_LOAD
| Field | Value |
|-------|-------|
| severity | HIGH |
| methods | `forName` (on `java.lang.Class`) |
| replacement | Declare explicit class references; use `@Reference` for OSGi service lookup |

### JSON Structure (each entry follows the existing `categories` array schema)

```json
{
  "name": "SUPPLY_CHAIN_PROCESS_SPAWN",
  "description": "OS process spawning from an OSGi bundle is a supply chain attack indicator.",
  "severity": "CRITICAL",
  "replacement": "Use Sling Jobs (org.apache.sling.event.jobs.JobManager) for async work.",
  "packages": [],
  "classes": ["java.lang.Runtime", "java.lang.ProcessBuilder"],
  "methods": ["exec", "start"],
  "annotations": []
}
```

## Acceptance Criteria

- [ ] Three new entries present in the `categories` array of `forbidden-apis.json`
- [ ] Each entry has non-empty `description`, `severity`, and `replacement` fields
- [ ] `ForbiddenApiCatalog.checkClass("java.lang.Runtime")` returns a match with severity CRITICAL
- [ ] `ForbiddenApiCatalog.checkMethod("exec")` returns a match
- [ ] `ForbiddenApiCatalog.checkClass("java.net.URLClassLoader")` returns a match with severity CRITICAL
- [ ] `ForbiddenApiCatalog.checkMethod("forName")` returns a match with severity HIGH
- [ ] All existing 116 tests still pass
