# Specification: REST endpoint GET /api/analysis/supply-chain

## Overview

**Feature**: New REST endpoint on `AnalysisController` that surfaces supply chain risks and
dependency delta as a single JSON response.
**Consumer**: CI/CD pipelines, security dashboards, Swagger UI.

## Functional Specification

### Endpoint

```
GET /api/analysis/supply-chain
```

Optional query params:
| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `projectPath` | String | (last scanned path) | Project root to analyze |
| `compareSnapshot` | String | null | Path to a previous snapshot file for dependency delta |

### Response Schema

```json
{
  "scannedAt": "2026-04-08T12:00:00Z",
  "projectPath": "/scan/my-aem-project",
  "supplyChainRisks": [
    {
      "riskType": "SNAPSHOT_IN_PRODUCTION_SCOPE",
      "severity": "HIGH",
      "message": "Dependency com.example:some-lib:1.0.0-SNAPSHOT is on compile scope",
      "dependency": {
        "groupId": "com.example",
        "artifactId": "some-lib",
        "version": "1.0.0-SNAPSHOT",
        "scope": "compile"
      }
    }
  ],
  "maliciousPatterns": [
    {
      "filePath": "core/src/.../MyService.java",
      "line": 42,
      "patternType": "LIFECYCLE_PROCESS_SPAWN",
      "detail": "@Activate method calls ProcessBuilder",
      "severity": "CRITICAL"
    }
  ],
  "dependencyDelta": {
    "added": [],
    "removed": [],
    "versionChanged": [],
    "repositoriesAdded": []
  },
  "summary": {
    "totalRisks": 1,
    "criticalCount": 0,
    "highCount": 1,
    "maliciousPatternsFound": 0
  }
}
```

If `compareSnapshot` is not provided, `dependencyDelta` is null.

### Error Responses
- `400 Bad Request` — `projectPath` not found
- `500 Internal Server Error` — analysis failed (with `errorMessage` field)

### OpenAPI Annotations
Use Spring's `@Operation`, `@ApiResponse` on the new method so Swagger UI auto-documents.
