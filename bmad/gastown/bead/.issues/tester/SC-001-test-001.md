# Test: SUPPLY_CHAIN categories in ForbiddenApiCatalog

## Context

Verify the three new SUPPLY_CHAIN categories are correctly loaded and matched by `ForbiddenApiCatalog`.

**Implementation**: bmad/gastown/bead/.issues/coder/SC-001-impl-001.md

## Test Requirements

- [ ] `ForbiddenApiCatalogTest` (existing or new inner class) covers all three new categories
- [ ] Tests confirm exact severity for each category
- [ ] Tests confirm negative cases (benign classes not matched)
- [ ] All 116 baseline tests still pass

## Test Scenarios

### Happy Path
| Input | Expected Match | Expected Severity |
|-------|---------------|------------------|
| `checkClass("java.lang.Runtime")` | present | CRITICAL |
| `checkClass("java.lang.ProcessBuilder")` | present | CRITICAL |
| `checkClass("java.net.URLClassLoader")` | present | CRITICAL |
| `checkMethod("exec")` | present | CRITICAL |
| `checkMethod("start")` | present | CRITICAL |
| `checkMethod("loadClass")` | present | CRITICAL |
| `checkMethod("forName")` | present | HIGH |

### Negative Cases
| Input | Expected |
|-------|---------|
| `checkClass("java.lang.String")` | empty |
| `checkClass("org.apache.sling.api.SlingHttpServletRequest")` | empty |
| `checkMethod("toString")` | empty (or only pre-existing matches) |

### Category Name Verification
- `checkClass("java.lang.Runtime")` → `ForbiddenMatch.categoryName()` == `"SUPPLY_CHAIN_PROCESS_SPAWN"`
- `checkClass("java.net.URLClassLoader")` → category == `"SUPPLY_CHAIN_REMOTE_CLASSLOAD"`
- `checkMethod("forName")` → category == `"SUPPLY_CHAIN_REFLECTION_LOAD"`

## Test File

`src/test/java/com/dede/cloud/ForbiddenApiCatalogSupplyChainTest.java`

```java
@SpringBootTest
class ForbiddenApiCatalogSupplyChainTest {

    @Autowired
    private ForbiddenApiCatalog catalog;

    @Test
    void processSpawn_Runtime_matchesCritical() {
        var match = catalog.checkClass("java.lang.Runtime");
        assertThat(match).isPresent();
        assertThat(match.get().severity()).isEqualTo(ForbiddenApiCatalog.Severity.CRITICAL);
        assertThat(match.get().categoryName()).isEqualTo("SUPPLY_CHAIN_PROCESS_SPAWN");
    }

    // ... similar tests for all rows above
}
```
